# REPORT: аудит продуктивності «Каталог репетиторів»

## 1. Умови вимірювання

- MacBook (Apple M4, 16 GB), macOS; Chrome 157.0.8103.51, інкогніто
- Збірка: `npm run build` + `npm run preview` (порт 4173)
- Performance: CPU 4× slowdown, Fast 4G, Disable cache; Lighthouse: mobile
- Кожна цифра «ДО» і «ПІСЛЯ» для трейсів: медіана з 3 запусків (трейси в `report/`)
- «Найдовша задача» = найдовший `RunTask` на main thread за запис; long task = задача > 50 мс
